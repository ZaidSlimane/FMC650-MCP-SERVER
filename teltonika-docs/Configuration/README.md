## Notes

- **23 RS-232/RS-485 and 27 Mobileye** are also part of the main manual work order (items 06 and 07); they are repeated here so every sub-link of the Configuration hub has its own directory.
- **19 ISOBUS**: all 6 figures are unarchived (CDX-verified 404s in the snapshot) — the page is text-only with an explicit note. The text includes the full ISOBUS parameter table (~65k chars).
- **04 System settings**, **18 LVCAN/FMS/Tachograph** and **29 Bluetooth 4.0** each lost one-to-three screenshots that the snapshot serves from never-captured `web.archive.org/images/...` paths — flagged at the end of the respective page.
- Tiny UI icons (15–34 px, e.g. `Export_html`, `Configurator-settings`, `Alert`) are below the harvest threshold and are intentionally not referenced in the markdown.
- Anchors in the hub (e.g. `FMC650_Status_info#GNSS_Info`) are sections **inside** the linked pages, not separate pages; each page here contains all of those sections.
- **Configurator companion notes (EN):** 33 PDF-derived notes (generated 2026-11-05, translated from French) were dispatched into 25 sub-pages, e.g. [`02_status-info/configurator/status.md`](02_status-info/configurator/status.md), with four notes under [`18_lvcan-fms-tachograph-data-elements/`](18_lvcan-fms-tachograph-data-elements/configurator/lvcan.md) and five under [`28_reefer-io/`](28_reefer-io/configurator/reefer-io.md). They complement — not replace — the verbatim English pages and are linked from each page's `## Configurator notes (EN)` block. Pages 01, 19, 21, 25 and 27 have no matching Configurator PDF.
