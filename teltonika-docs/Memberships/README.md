## Notes

- **Hub has no content of its own** — only the three links above. This is why there is no page file at the `Memberships/` root.
- **03 FM Battery** is a *shared* page (`FM_Battery_FMC650`, not an `FMC650_…` page) and repeats the WEEE wording, but registers a different number: the battery registration `25449079` versus the device WEEE registration `29661125`. Its attachment image is unarchived (CDX-verified 404) and is flagged in the page.
- **02 WEEE** is the only WEEE source in this knowledge base. It is **not** linked from the Certification & Approvals hub snapshot, so it lives here rather than under [`../Certification/`](../Certification/README.md); the Certification README cross-references it. The 2026-04-22 capture is text-identical to the 2026-01-24 one the archived browser session resolves to — explained in the page.
- **01 Bluetooth® SIG** uses the `…Bluetooth%C2%AE_SIG` title (with the registered-trademark character); the plain `FMC650_Bluetooth_SIG` spelling redirects to it.
- Snapshots are the latest available captures at extraction time (CDX-verified).
