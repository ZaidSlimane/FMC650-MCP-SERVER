# FMX6 dimensions — from the outline drawing

Source image: [`FMX6_dimensions.png`](../assets/FMX6_dimensions.png) (600×424, isometric line drawing).

This is the **generic TELTONIKA FMX6 family shell** (shared by FMC640/FMC650-class enclosures): a rectangular case, "TELTONIKA" logo and "FMX6" lettering on the top face.

## Overall dimensions (as printed in the drawing)

| Dimension | Value |
| --- | --- |
| Length (long face, front edge) | 104.5 mm |
| Width (long face, bottom edge) | 76.8 mm |
| Height (vertical edge, front corner) | 29.2 mm |

Callout lines in the drawing:
- `104.5 mm` — dashed line measuring the long bottom-left face (front-to-back edge with the connector recesses).
- `76.8 mm` — dashed line measuring the bottom-right face (short end edge containing the connector block).
- `29.2 mm` — dashed line measuring the vertical front corner edge (case height without the mounting lips).

## Visible features in the drawing

- **Top face** — `TELTONIKA` logo, large `FMX6` lettering.
- **Short right end face** — stepped/notched profile with a raised rectangular tongue and a rectangular opening: this is where the **Mini-USB socket** sits (device rear, "USB for configuration").
- **Long left face** — two rectangular connector recesses seated on the edge: the interface socket block (the **2×10 socket** end; compare [2×10 pinout](../../00_first-start/schemas/2x10-pinout.md)).
- **Case top edges** — serrated/milled style line (snap-fit case halves, consistent with the "2-piece case, screws on top" construction).

> **Note:** the drawing's printed dimensions (104.5 × 76.8 × 29.2 mm) do **not** match the device page text body ("Dimensions: L(104,1mm)xW(76,8mm)xH(31,5mm)") — length differs by 0.4 mm and height by 2.3 mm. The mismatch is inherited from the wiki source; the drawing is the generic FMX6-family shell while the figures table is FMC650-specific.
